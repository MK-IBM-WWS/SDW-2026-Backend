# Лабораторная работа №1 — тарифы облачного хостинга

Интерфейс повторяет digitalocean.com: чёрный фон, белые элементы, тёмно-зелёная активная вкладка `#283A23`, голубой акцент `#6FE0ED`, скруглённые карточки и hover-состояния.

В проекте нет JavaScript и базы данных. Все данные находятся в единственной коллекции `[]CloudTariff`. Изображения и видео загружаются браузером из MinIO.

## Что реализовано

- лента с автоматически проигрываемым вертикальным видео;
- открытие ленты по ID тарифа;
- `?next=true` для перехода к следующему опубликованному тарифу;
- нативный HTML-элемент `details` для раскрытия описания по ссылке «ещё...» без JavaScript;
- страница единственного черновика с заполняемыми полями без сохранения;
- плитка опубликованных тарифов в два столбца;
- серверная фильтрация по цене: без фильтра, до 1 000, до 10 000 и до 500 000 рублей;
- сохранение выбранного значения фильтра после GET-запроса;
- вычисление числа лайков методом `LikeCount()` по массиву ID пользователей;
- статусы `черновик`, `опубликован`, `удалён`;
- исключение удалённых тарифов из всех публичных страниц;
- отдельные атомарные поля тарифа и только один разрешённый вложенный массив — ID пользователей, поставивших лайк;
- отдельные ключи `ImageKey` и `VideoKey` для объектов MinIO;
- отдельный CSS-файл.

## Назначение каждого файла

| Файл | Содержание и назначение |
| --- | --- |
| `.env.example` | Пример адреса MinIO, имени bucket и адреса Go-сервера. Go не загружает этот файл автоматически. |
| `.gitignore` | Исключает настройки IDE, локальный `.env` и сборочные файлы. |
| `go.mod`, `go.sum` | Описывают Go-модуль и фиксируют зависимости Gin и Logrus. |
| `cmd/tariffs/main.go` | Минимальная точка входа: запускает сервер и обрабатывает ошибку запуска. |
| `internal/api/server.go` | Создаёт репозиторий и обработчик, подключает шаблоны, CSS и GET-маршруты. |
| `internal/app/handler/handler.go` | Принимает параметры URL/query, вызывает репозиторий и передаёт данные в HTML-шаблоны. |
| `internal/app/repository/repository.go` | Содержит модель, статусы, методы получения данных, подсчёт лайков и построение URL MinIO. |
| `internal/app/repository/tariffs.go` | Единственная коллекция тарифов: опубликованные записи, один черновик и одна удалённая запись. |
| `resources/images/interface-background.png` | Фоновый графический элемент, извлечённый из согласованного Figma-макета. Это не изображение тарифа. |
| `resources/images/home.png`, `document.png`, `catalog.png` | Оригинальные иконки нижней навигации из Figma-макета. |
| `resources/images/ram.png` | Оригинальная иконка оперативной памяти из Figma-макета для страницы ленты. |
| `resources/styles/style.css` | Все стили трёх страниц, мобильная компоновка, карточки, навигация, hover/focus-состояния. |
| `templates/tabbar.html` | Общая нижняя панель трёх вкладок. |
| `templates/tariff_feed.html` | Лента с видео, характеристиками, лайками, описанием и кнопкой следующего тарифа. |
| `templates/tariff_draft.html` | Форма единственного черновика; значения можно изменять в браузере, но сохранения нет. |
| `templates/tariff_tiles.html` | Двухколоночная плитка и GET-форма серверного фильтра по цене. |
