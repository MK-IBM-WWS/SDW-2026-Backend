<h1>Оценка стоимости облачного хостинга для веб-проекта</h1> 
<hr>
<h3>Логика работы системы</h3>
Пользователь указывает прогнозируемую нагрузку своего веб-проекта и выбирает несколько тарифов разных облачных провайдеров. Система рассчитывает примерную месячную стоимость размещения проекта на каждом выбранном тарифе. Модератор управляет списком доступных тарифов и подтверждает заявки. Стоимость хостинга зависит от требуемых вычислительных ресурсов, объёма оперативной памяти, дискового пространства и сетевого трафика. Поэтому характеристики тарифа необходимо хранить в таблице услуг, а требования проекта — в заявке. В связующей таблице между заявкой и тарифом можно хранить результат расчёта стоимости и комментарий пользователя или модератора.

<h3>Поля в таблицах по теме</h3>
Таблица CloudTariffs — услуги:
<ol>
  <li>tariff_id - ID</li>
<li>tariff_name - название тарифа</li>
<li>cpu_cores — количество виртуальных ядер CPU</li>
<li>ram_gb — объём оперативной памяти, ГБ</li>
<li>storage_gb — доступное дисковое пространство, ГБ</li>
<li>monthly_price — базовая стоимость тарифа за месяц</li>
<li>provider — облачный провайдер: AWS, Google Cloud, Azure, Яндекс Cloud, SberCloud и т. п</li></ol>

Таблица HostingRequests — заявка:
<ol>
<li>hosting_request_id - ID</li>
<li>required_cpu_cores — требуемое количество ядер CPU</li>
<li>required_ram_gb — необходимый объём RAM</li>
<li>required_storage_gb — требуемое дисковое пространство</li>
<li>project_name — название веб-проекта</li></ol>

Таблица CostCalculation - м-м:
<ol>
<li>cost_calculation_id - ID</li>
<li>tariff_id - выбранный тариф</li>
<li>hosting_request_id - полученная заявка</li>
<li>calculated_monthly_cost — рассчитанная месячная стоимость размещения</li>
<li>is_suitable — подходит ли данный тариф под требования проекта</li>
<li>comment — комментарий пользователя или модератора</li></ol>

<h3>Логика расчёта</h3>
Для каждого выбранного тарифа система сравнивает:
<ul>
<li>required_cpu_cores <= cpu_cores</li>
<li>required_ram_gb <= ram_gb</li>
<li>required_storage_gb <= storage_gb</li>
<li>Если ресурсов тарифа недостаточно, is_suitable = false.</li>
<li>Если ресурсов хватает, тариф считается подходящим. Базовая стоимость: calculated_monthly_cost = monthly_price</li>
<li>Поле calculated_monthly_cost система может автоматически заполнять после перевода заявки в статус «Рассчитана» или «Завершена».</li></ul>
