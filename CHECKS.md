# Проверка подготовленного проекта

Выполнено в среде Linux с Go 1.25.0:

- `go mod tidy` — успешно.
- `go test -race ./...` — успешно.
- `go vet ./...` — успешно.
- `go build ./cmd/tariffs` — успешно.
- JavaScript: `node --check` для api-forms.js, draft-preview.js и media-fallback.js — успешно.
- Коллекция Postman и окружение — корректный JSON, 44 запроса.

Тесты хранилища используют SQLite в памяти; HTTP — Gin/httptest; ошибки загрузки — тестовый S3 HTTP-сервер с настоящим MinIO Go SDK.
Проверены жизненный цикл тарифа, ограничения автора, один черновик, фильтрация, лайки без дублей, сокрытие удалённых, вложенная сериализация без пароля, входные поля, настоящие example.jpg/example.mp4, компенсация файлов при сбое второго upload или БД, шаблоны.

Полный запуск PostgreSQL + MinIO в Docker на Fedora и прогон настольного Postman здесь не выполнялись. Для этих проверок приложены FEDORA.md и POSTMAN.md.

После исправления медиа дополнительно проверены статические URL при пустом имени, перенаправление отсутствующего объекта на /static/media/example.*, сохранение 404 для невидимого тарифа и браузерный обработчик error (изображение, видео/source, autoplay, защита от зацикливания).
