# Коллекция для демонстрации ЛР4

Импортируйте `Lab4_Demo.postman_collection.json` заново и открывайте запросы из импортированной коллекции. Задайте `base_url` и вставьте JWT из Swagger в переменную `token` без слова Bearer. Для публикации сохраните ID своего черновика в `tariff_id`.

Ручные строки Headers удалены во всех запросах. Authorization формируется помощником Bearer Token; Content-Type — настройкой Body. Для raw-тел выбран JSON, создание тарифа использует настоящую form-data. Для загрузки изображения и видео выберите файлы в соответствующих строках формы и включите эти строки. Postman добавляет multipart boundary самостоятельно.

У гостевых проверок выбрано No Auth: это необходимо для демонстрации публичного списка и отказа в публикации. В остальных запросах с JWT применяется Bearer Token. Заголовки Host, Content-Length, User-Agent, Accept-Encoding и Connection формирует сам Postman.

Требование сделать абсолютно все галочки белыми средствами JSON-коллекции не выполнено: поддерживаемого свойства цвета или принудительного режима недоступности для всех заголовков у формата коллекции нет. На приложенном образце верхние и нижние строки имеют разное поведение интерфейса. Настройка Bearer Token создаёт автоматический Authorization, но не меняет цвет остальных служебных строк. Отключать необходимые HTTP-заголовки ради цвета нельзя: это может нарушить запрос.

Показатель отправки заголовка — его наличие в фактическом запросе, а не цвет галочки. В Postman Console можно проверить отправленный запрос. При наведении на значок информации у заголовка Postman объясняет его источник.
