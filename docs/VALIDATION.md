# Выполненная проверка

Рабочее окружение Linux: Go 1.25.7, Node.js 24.22.1, PostgreSQL 16.15, Redis 7.0.15.
В Compose проекта настроена PostgreSQL 17; Docker/SELinux и запуск непосредственно на Fedora в этом окружении не проверялись.

- `go test ./...`: пройдено.
- `go vet ./...`: пройдено.
- `go test -race ./internal/app/feed`: пройдено.
- `npm ci`, `npm run generate-api`, `npm run build`: пройдено.
- На настоящей PostgreSQL генератор создал 120000 строк. Повторные запуски добавили 0.
- Через настоящий HTTP API проверены страницы, непересечение соседних страниц, фильтр цены и `total`, отклонение неверных лимитов.
- В настоящем Redis проверены LIST из 100 JSON-карточек, 100 уникальных ID, номера 1..100, получение каждой карточки в сохранённом порядке, новая сотня с №101 и повтор №101 без новой генерации.
- Проверены отдельные ключи гостя/авторизованного пользователя и актуальность лайков после их изменения.
- Через jsdom исполнен настоящий собранный React JS с запросами к Vite/Go API: страницы 1/2, применение слайдера с возвратом на страницу 1, статистика БД, переходы в ленте №1→2→3, вход, признак владельца, авторизованная лента, лайк/отмена, выход. Сессионная cookie недоступна из `document.cookie`.
- Полноценный визуальный прогон в Chromium недоступен из-за ограничения Unix-сокетов рабочего окружения. DOM-проверка не заменяет проверку отрисовки браузером.
- В интеграционных проверках новой лабораторной использовались услуги с пустыми медиа. Для неизменённого обращения к S3 при старте API использована тестовая заглушка bucket/location. Загрузка/публикация медиа проверялась существующими тестами проекта; запуск настоящего MinIO в этом окружении не выполнялся.
